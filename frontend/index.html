                          Demo Activity
                          
              Safe demo
            
                          
            
          
                          

          
                          
            
                          This runs real, registered operations through the Command Center’s authorization, confirmation, execution and verification framework, restores every temporary change, and records real execution traces. It is not itself a registered operation.
                          
            
                          What will happen
                          
            
                            
              
                          1. Journal setting: PurgeArchived is switched to the opposite value, verified, then restored to its original value and verified.
                            2. 
              
                          2. Web application description: on a safe web application (/csp/user when available; never a System app, /api/admin or /api/mgmnt), the description is temporarily changed, verified, then restored and verified.
                            3. 
              
                          3. Dry runs only: Mount Database and Run Task Now are simulated when a valid candidate exists — nothing is mounted or run. Otherwise they are skipped.
                            4. 
            
                          
            
                          The rehearsal stops at the first failure and always tries to restore anything it changed. Nothing is sent until you confirm.
                          
            
                          
              
              
            
                          

            
                          Issue Resolution Rehearsal (separate, manual)
                          
            
                            
              
                          1. Create a real issue: the IPM database is checked (Dismount dry run and safety rules), then dismounted.
                            2. 
              
                          2. Detect: the Command Center issue detection reports it as a Command Center Issue.
                            3. 
              
                          3. Fix: the Resolve Issues operation (Mount Database) mounts IPM again, then IPM being mounted and the issue being gone are verified.
                            4. 
            
                          
            
                          Only IPM is touched. If any step fails after the dismount, IPM is mounted again. Never part of the automatic startup rehearsal.
                          
            
                          
              
            
                          
          
                          

          
                          
            
            Running the rehearsal — each change is verified and restored…
